# Boca a Boca · San Patricio del Chañar

Primera versión de una plataforma comunitaria estática para conectar vecinos, oficios, servicios, recomendaciones e intercambios.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable a celulares y computadoras.
- `app.js`: buscador y catálogo de familias de oficios.

## Estado actual
- Interfaz inicial navegable.
- Buscador funcional sobre 24 familias de oficios y tareas.
- Secciones para las seis formas de participación.
- Espacios visuales reservados para publicidad local.
- No se publican prestadores ficticios ni recomendaciones inventadas.

## Próximas etapas
1. Definir el alcance territorial y quiénes pueden ofrecer servicios.
2. Configurar un canal real de recepción de publicaciones y moderación.
3. Incorporar fichas de prestadores con consentimiento y datos comprobados.
4. Activar los espacios publicitarios con identificación visible.
5. Probar en teléfonos y revisar accesibilidad.

## Importante
GitHub Pages sirve el sitio, pero por sí solo no recibe ni almacena publicaciones compartidas entre visitantes. El formulario comunitario se conectará en una etapa posterior a un canal externo o servicio de datos. No se debe presentar una publicación como enviada hasta que exista esa integración.
